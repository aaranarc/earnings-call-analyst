# Verification records

`vercel-production-checks.json` records the public deployment and a successful live cited answer. `vercel-production-desktop.png`, `vercel-production-mobile.png` and `vercel-production-answer.png` show that deployment.

- `vercel-preview-checks.json`: browser checks of the redesigned Python interface on Vercel, including the source commit.
- `vercel-streamlit-preview.png` and `vercel-streamlit-preview-mobile.png`: the hosted Streamlit design.
- `vercel-streamlit-answer.png`: a real cited Kotak Q1 FY27 answer from the Vercel preview; not a saved-example screen.
- `streamlit-migration.json` and its test logs: the earlier local migration checks, before the hosted redesign. Statements about no push/deployment in that file refer to that earlier stage.
- `streamlit-redesign-*.png`: local ASGI browser checks.

Always compare a record's commit/URL with the current release. Passing HTTP checks does not establish answer faithfulness or validate financial forecasts. Final gold evaluation and blind numeric labelling remain separate work.
